# max-1c-bot
Интеллектуальный чат-бот в мессенджере MAX для поиска и подбора товаров в системе 1С

## Стек
- Python / FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
- MAX API

## Запуск локально
1. Создать `.env` по образцу.
2. Запустить:
   ```bash
   docker-compose up --build
3. Проверить Swagger: http://localhost:8000/docs
## Функции
- Поиск товаров по категориям, брендам, бюджету.
- Команды: "покажи второй", "сравни первый и второй", "ещё", "покажи все".
- Поддержка fallback локальной БД, имитация данных из 1С.
